# wav-
第一版：TIM3更新事件触发DMA更改TIM2->CCR1，从而改变占空比。
但这一版存在问题：如果想要两个声道，则需要同时改变TIM2->CCR1和TIM2->CCR2。
这对普通DMA难以实现，因为DMA传输给的地址是固定的。
所以下一版的双声道会把TIM3定时器转到TIM1高级定时器上，同时用TIMER_DMA_BURST同时改变CCR1和CCR2

第二版：运用了高级定时器将TIM3定时器转到TIM1高级定时器上，同时用TIMER_DMA_BURST同时改变CCR1和CCR2，做到了双声道
同时增加了OLED屏幕的显示，但还有问题，旋转按钮OLED屏幕的显示会占用CPU，导致歌曲卡顿

第三版：优化了整体结构，利用了双缓冲获取的速度快于输出的速度的这一段时间刷新OLED,同时分两次刷新OLED，解决了旋转按钮歌曲卡顿的问题
